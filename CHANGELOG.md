# Журнал изменений
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer 2.0](https://semver.org/lang/ru/).

## Несколько офлайн-систем (C: и D:)
- Исправлена причина: имена загруженных кустов были одинаковыми для всех Windows (WRO_SYSTEM…), поэтому второй диск показывал данные первого. Теперь имя уникально для тома (WRO_D_SYSTEM, WRO_D_NU_user…), при смене файла куст перезагружается.
- Реестр: дерево по системам («D:\ … [офлайн]» → кусты), адреса в виде D:\SYSTEM\ControlSet001, меню Файл: загрузить/выгрузить диск, куст из файла, выгрузить выбранный/всё; выбранная в главном окне система загружается автоматически; резервные копии по тому реального куста.
- Автозагрузка и Установленные приложения: пересканирование сразу при смене диска в списке.

## [1.0.0-rc1]
### Добавлено
- Самопроверка целостности при запуске: SHA-256 всех файлов пакета по `MANIFEST.sha256`, состояние подписи Authenticode (`WinVerifyTrust`, загружается динамически).
  Изменённые исполняемые файлы — предупреждение и запись в журнал; изменённые сценарии/словари (их правят пользователи) — только отметка в журнале.
- `res/version.h` — единственный источник версии (код, ресурсы exe, пакет).
- `sign_exe.bat` (подпись SHA-256 + метка времени RFC 3161), `build_msvc_analyze.bat` (/analyze), поддержка ARM64 в `make_package.bat`, `MANIFEST.sha256` в пакете.
- Документы выпуска: RELEASE.md, RELEASE_CHECKLIST.md, PRIVACY.md, SECURITY.md, THIRD_PARTY_NOTICES.md, LICENSE.txt (шаблон).
### Добавлено (ремонт: программы и файлы офлайн)
- «Установленные приложения офлайн»: список программ из реестра офлайн-Windows (машина, 32-бит, пользователи), антивирусы и средства защиты выделены; принудительное удаление — отключение служб/драйверов/автозапуска программы, перенос папки в карантин `WinRepair_Removed` (обратимо) или удаление, удаление записи с копией .reg; защита системных папок.
- «Офлайн-проводник»: дерево дисков и таблица файлов, копирование/вырезание/вставка, переименование, новая папка, поиск (подпапки, маски), свойства, снятие атрибутов, получение прав владельца (takeown + icacls), удаление в карантин по умолчанию, окончательное удаление с двойным подтверждением для файлов Windows; меню правой кнопки и клавиши как в Проводнике.
- Реестр офлайн в стиле regedit: строка меню (Файл, Правка, Вид, Избранное), адресная строка (Enter), строка состояния, переименование значений и разделов, избранное, клавиши F2/F3/F5/Del/Ctrl+F.
- BCD: выделенные карточки «Хранилище BCD» и «Режим следующей загрузки».
- Реестр: строка поиска (имена разделов, имена значений, данные; можно только в выбранном разделе), результаты в отдельном окне — двойной щелчок открывает раздел и выделяет значение; меню правой кнопки в дереве и списке значений.
### Изменено (оформление)
- Описание команды теперь показывается всплывающей подсказкой при наведении курсора на кнопку (заголовок + что делает команда); нижняя карточка описания убрана.
- Новая тема: шрифт Segoe UI, светлый фон, шапка с логотипом и градиентом, **кнопки окрашены по назначению** (синие — диагностика только чтение; бирюзовые — мастера и сценарии; оранжевые — изменяют систему; зелёные — защита и сохранение; красная — «Выход»), подсветка при наведении, легенда цветов, тёмный журнал.
