# Журнал изменений
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer 2.0](https://semver.org/lang/ru/).

## Несколько офлайн-систем (C: и D:)
- Исправлена причина: имена загруженных кустов были одинаковыми для всех Windows (WRO_SYSTEM…), поэтому второй диск показывал данные первого. Теперь имя уникально для тома (WRO_D_SYSTEM, WRO_D_NU_user…), при смене файла куст перезагружается.
- Реестр: дерево по системам («D:\ … [офлайн]» → кусты), адреса в виде D:\SYSTEM\ControlSet001, меню Файл: загрузить/выгрузить диск, куст из файла, выгрузить выбранный/всё; выбранная в главном окне система загружается автоматически; резервные копии по тому реального куста.
- Автозагрузка и Установленные приложения: пересканирование сразу при смене диска в списке.

## [1.0.0-rc1]
### Добавлено
- Самопроверка целостности при запуске: SHA-256 всех файлов пакета по `MANIFEST.sha256`, состояние подписи Authenticode (`WinVerifyTrust`, загружается динамически).
  Изменённые исполняемые файлы — предупреждение и запись в журнал; изменённые сценарии/словари (их правят пользователи) — только отметка в журнале.
- `res/version.h` — единственный источник версии (код, ресурсы exe, пакет).
- `sign_exe.bat` (подпись SHA-256 + метка времени RFC 3161), `build_msvc_analyze.bat` (/analyze), поддержка ARM64 в `make_package.bat`, `MANIFEST.sha256` в пакете.
- Документы выпуска: RELEASE.md, RELEASE_CHECKLIST.md, PRIVACY.md, SECURITY.md, THIRD_PARTY_NOTICES.md, LICENSE.txt (шаблон).
### Добавлено (ремонт: программы и файлы офлайн)
- «Установленные приложения офлайн»: список программ из реестра офлайн-Windows (машина, 32-бит, пользователи), антивирусы и средства защиты выделены; принудительное удаление — отключение служб/драйверов/автозапуска программы, перенос папки в карантин `WinRepair_Removed` (обратимо) или удаление, удаление записи с копией .reg; защита системных папок.
- «Офлайн-проводник»: дерево дисков и таблица файлов, копирование/вырезание/вставка, переименование, новая папка, поиск (подпапки, маски), свойства, снятие атрибутов, получение прав владельца (takeown + icacls), удаление в карантин по умолчанию, окончательное удаление с двойным подтверждением для файлов Windows; меню правой кнопки и клавиши как в Проводнике.
- Реестр офлайн в стиле regedit: строка меню (Файл, Правка, Вид, Избранное), адресная строка (Enter), строка состояния, переименование значений и разделов, избранное, клавиши F2/F3/F5/Del/Ctrl+F.
- BCD: выделенные карточки «Хранилище BCD» и «Режим следующей загрузки».
### Добавлено (контекстные меню и поиск)
- Вкладки главного окна растянуты на всю ширину; длинные названия переносятся на две строки, а не обрезаются.
- Правая кнопка мыши везде: на команде (запустить, что делает, копировать название/описание), в журнале (копировать, выделить всё, сохранить, открыть, очистить), на вкладках (переход на вкладку), в каталоге команд (выполнить, копировать название/текст команды).
- Правая кнопка работает только по своему объекту: в таблице любого окна — «копировать строку / таблицу»; на кнопках, подписях и пустых местах окон-инструментов меню нет.
- Автозагрузка — по образцу Sysinternals Autoruns: вкладки категорий (Всё, Вход и автозапуск, Службы, Драйверы, Планировщик, Прочее), быстрый фильтр по тексту в любом столбце (Ctrl+F), раскраска строк (розовый — подозрительно, жёлтый — файл не найден, серый — отключено), меню записи (включить/отключить, изменить, удалить, перейти к записи, поиск в интернете, свойства файла, копировать), клавиши Del, Ctrl+C, Ctrl+J, F5.
- Вкладки главного окна: ниже по высоте, без стрелок прокрутки (все 8 видны), длинные названия уменьшают шрифт, затем переносятся.
- Реестр: строка поиска (имена разделов, имена значений, данные; можно только в выбранном разделе), результаты в отдельном окне — двойной щелчок открывает раздел и выделяет значение; меню правой кнопки в дереве и списке значений.
### Изменено (оформление)
- Описание команды теперь показывается всплывающей подсказкой при наведении курсора на кнопку (заголовок + что делает команда); нижняя карточка описания убрана.
- Новая тема: шрифт Segoe UI, светлый фон, шапка с логотипом и градиентом, **кнопки окрашены по назначению** (синие — диагностика только чтение; бирюзовые — мастера и сценарии; оранжевые — изменяют систему; зелёные — защита и сохранение; красная — «Выход»), подсветка при наведении, легенда цветов, тёмный журнал.
- Логотип и иконка программы (`res/winrepair.ico`, 16–256 px; исходник `tools/make_icon.py`, PNG в `docs/branding/`). Кнопка **«Выход»** в шапке.
- Название, правообладатель и copyright задаются в одном месте — `res/version.h` (`WR_PRODUCT`, `WR_COMPANY`, `WR_COPYRIGHT`).
- Шапка: название ОС крупно и светло, рядом «таблетки»-статусы (архитектура, WinPE/WinRE, **«Администратор: да» зелёным / «БЕЗ прав» красным**, версия).
- «Целевая ОС» выделена рамкой и светло-синей панелью, крупный шрифт списка.
- Цветная метка категории теперь **полоска под текстом кнопки** (а не слева); кнопки растягиваются по ширине, высота вкладки подстраивается под содержимое.
- Журнал на светлом фоне, моноширинный шрифт крупнее, **строки окрашены по уровню** (ошибка — красная, предупреждение — янтарная, OK — зелёная, заголовки операций — синие жирные, вывод утилит — приглушённый). Используется RichEdit; если `msftedit.dll` нет (часть WinPE) — обычное поле.
- Параметры перенесены **внутрь своих вкладок**, под кнопки, с пояснением к каждой: «Диски» — период и расширенный режим (chkdsk /scan); «Целостность» — расширенный режим (DISM /ScanHealth), **источник DISM (/Source)** с примерами и точка восстановления без лимита 24 ч; «События» — период; «Сеть» — хост и порт проверки. Фон окна белый, как у вкладок.
- «Мастер исправлений (SmartFix / Windows Repair)» → **«Мастер исправлений после заражений»**.
- **Вкладки** крупнее (шрифт 10,5 pt), раскрашены по назначению; активная заливается цветом с белым жирным текстом, у неактивных цветная линия снизу.
- **Карточка описания** под вкладками: при наведении на любую команду показывает название, категорию (цвет) и подробное описание, что команда делает (30 команд, RU/EN); после запуска остаётся описание последней команды, оно же пишется в журнал («Назначение: …»). В «Каталоге команд» описание уже показывалось для каждой из 83 команд.
- Общий шрифт 9,5 pt; **кнопки во всех окнах инструментов — жирные**.
- Кнопка **«Копировать журнал»** (в буфер обмена) рядом с «Сохранить журнал…».
### Резервные копии
- Одна копия на систему: `Data\Backups\vol_<серийный номер тома>\{hives,files,bcd}`. Копия обновляется один раз за сеанс перед первым изменением и заменяет прежнюю, поэтому папка больше не растёт (раньше каждый сеанс создавал новую папку `<время>_hives` с копиями всех кустов).
- При выходе программа спрашивает: удалить копии / оставить / не выходить. Кнопка «Резервные копии…» (вкладка «Инструменты ремонта»): размер, удаление, открыть папку.
- При запуске: копии от других систем (другой компьютер/флешка) и старого формата предлагаются к удалению — на новой системе папка должна быть пустой.
### Исправлено
- Окно «Сценарии ремонта» было пустым при запуске `build\WinRepair.exe` из дерева исходников (папка `Playbooks` лежит уровнем выше). Теперь сценарии **встроены в exe** (RCDATA 100+), а `Playbooks\` рядом с exe, `..\Playbooks\` и `Data\Playbooks\` переопределяют встроенные по `id`.
- Кракозябры в выводе внешних программ (например, `pnputil /enum-drivers`: «╤ыєцхсэр  яЁюуЁрььр»). Утилиты пишут в канал то в OEM (866), то в ANSI (1251), то в UTF-8. Кодировка теперь определяется автоматически по содержимому (сравнивается правдоподобность русского текста), решение запоминается на время работы процесса; склейка UTF-8 на границе блоков.
