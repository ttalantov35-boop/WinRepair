\xef\xbb\xbfWinRepair Toolkit — быстрый старт
=================================

Состав папки
  WinRepair_x64.exe / WinRepair_x86.exe  — программа (один файл, без установки и зависимостей)
  Run-WinRepair.cmd                      — запускает нужную версию с любой буквы диска (удобно в WinPE/WinRE)
  Playbooks\                             — сценарии ремонта и симптомы (*.wrp); описание формата: Playbooks\README_PLAYBOOKS.md
  Tools\                                 — необязательные инструменты (см. Tools\README.txt, например cdb.exe для разбора дампов)
  Data\                                  — создаётся при первом запуске: Logs (журналы), Reports (отчёты), Backups (копии кустов и BCD)
  winpeshl.ini.example, startnet.cmd.example — примеры автозапуска для собственных образов WinPE
  SHA256.txt                             — контрольные суммы exe

Запуск
  1. Скопируйте папку WinRepair в корень флешки (\WinRepair\).
  2. Загрузитесь в WinPE (например, Sergei Strelec) или WinRE. Откройте флешку и запустите Run-WinRepair.cmd.
  3. В списке «Целевая ОС» выберите установленную Windows (нажмите «Обновить»). Если диска нет — «BitLocker и драйверы хранилища».
  4. Начните с «Мастер "Что случилось?"» на вкладке «Обзор».

Важно
  * В WinPE/WinRE папка Data создаётся на ОЗУ-диске и пропадёт при перезагрузке. Нажмите «Сохранить журналы и отчёты на диск…» (вкладка «Инструменты ремонта»)
    или запускайте программу с флешки — тогда Data создаётся рядом с exe.
  * Каждое изменение системы подтверждается отдельно и записывается в журнал (Data\Logs\changes_*.log). Копии кустов реестра и BCD — в Data\Backups.
  * Сценарии из папки Playbooks могут запускать любые программы — используйте только доверенные.
  * Вход в WinRE: «Инструменты ремонта» → «WinRE: вход в среду восстановления…». Можно собрать «WinRE + WinRepair» — копия winre.wim с программой.

Автозапуск в собственном образе WinPE (ADK)
  Скопируйте WinRepair_x64.exe в Windows\System32 образа и добавьте winpeshl.ini (пример рядом) — программа запустится первой.
  Либо добавьте строку из startnet.cmd.example в startnet.cmd.
