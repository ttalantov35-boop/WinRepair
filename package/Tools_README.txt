Необязательные инструменты WinRepair
====================================
cdb.exe (Debugging Tools for Windows) — для полного разбора дампов (!analyze -v).
  Положите cdb.exe в эту папку (Tools\cdb.exe, Tools\x64\cdb.exe или Tools\x86\cdb.exe) вместе с остальными файлами отладчика из Windows SDK.
  Без cdb программа всё равно читает заголовок дампа (код BugCheck, параметры, категория).
Для символов нужен доступ в интернет; без сети разбор будет неполным.
