; Справка WinRepair Toolkit (русский). Источник встроенной справки: при сборке файл попадает внутрь WinRepair.exe.
; В выпускаемой программе справка только встроенная — файлы рядом с exe не читаются, подменить её нельзя.
; Проверить правки без пересборки можно в сборке автора: build_msvc.bat edit → окно справки → «Изменить справку…».
; Формат простой:
;   # Раздел {#метка}      — раздел (метка нужна, чтобы F1 открывал нужное место)
;   ## Подраздел           — подраздел
;   - пункт                — пункт списка
;   ; комментарий          — строка не показывается
; Остальные строки — обычный текст. Пустая строка — новый абзац.
; Готовый текст сохраните здесь (help\help.ru.txt в исходниках) и соберите программу обычным build_msvc.bat.

# Начало работы {#start}
WinRepair — один файл WinRepair.exe без установки. Он проверяет и чинит Windows 10/11, в том числе ту, что не загружается. Работает в обычной Windows, в WinPE и в WinRE. .NET, PowerShell и VC++ Redistributable не нужны.

- Запустите программу от имени администратора. Без этих прав в заголовке будет красная метка, и большинство исправлений не сработает.
- В поле «Целевая ОС» выберите Windows, которую нужно проверить или починить. Чтобы чинить другой диск, выберите офлайн-систему (C:, D: и т. д.). После подключения диска нажмите «Обновить».
- Для работы из WinPE или WinRE скопируйте программу на флешку и запустите оттуда. Удобнее собрать свою флешку WinPE (раздел «Загрузочная флешка WinPE»).

Файлы программы:
- WinRepair_x64.exe — основной, для 64-битных Windows, WinPE и WinRE;
- WinRepair_x86.exe — для 32-битных систем;
- WinRepair_arm64.exe — для Windows на ARM (Snapdragon).

## Клавиши и кнопки
- F1 или кнопка «Справка» вверху — эта справка. В окнах инструментов F1 открывает раздел про это окно.
- «Командная строка (администратор)…» на вкладке «Обзор» — консоль cmd с правами администратора (раздел «Командная строка»).
- «English / Русский» — язык интерфейса.
- Правый клик по журналу или таблице — копирование, сохранение, другие действия.

# Главное окно {#main}
Сверху — заголовок с метками: разрядность, WinPE/WinRE, права администратора, версия программы. Справа в заголовке — «Справка» (зелёная), «English / Русский» (фиолетовая) и «Выход» (красная). Ниже — настройки, вкладки с кнопками действий и журнал.

Цвет кнопки — назначение: синий — диагностика (только чтение), бирюзовый — мастера, сценарии, каталог команд и командная строка, оранжевый — инструменты ремонта (меняют систему, всегда спрашивают подтверждение), зелёный — защита (точки восстановления, резервные копии, сохранение данных), серый — служебное.

- Целевая ОС + «Обновить» — какую Windows проверять и чинить.
- Период, дней — за сколько дней смотреть события и синие экраны (по умолчанию 3).
- Расширенный режим — добавляет долгие проверки ScanHealth и chkdsk /scan.
- Точка восстановления: игнорировать лимит 24 ч — позволяет создать точку чаще раза в сутки.
- Хост и порт — для сетевой диагностики (по умолчанию www.microsoft.com:443).
- Источник DISM (/Source) — путь к install.wim/esd, чтобы восстанавливать файлы без интернета.
- Журнал внизу — что делает программа. Рядом кнопки «Отмена», «Открыть папку отчётов», «Открыть лог-файл», «Сохранить журнал…», «Копировать журнал», «Очистить».

На экране журнал показывает только главное. Полный вывод команд пишется в лог-файл (кнопка «Открыть лог-файл»).

# Вкладки и функции {#tabs}
Вкладки 1–7 в основном только читают данные. Систему меняют «ИСПРАВИТЬ целостность», «Создать точку восстановления» и инструменты вкладки «Инструменты ремонта». Каждое изменение подтверждается.

- Обзор — мастер «Что случилось?», сценарии ремонта, загрузочная флешка WinPE, полная диагностика + HTML-отчёт, каталог команд, командная строка (администратор), «О программе WinRepair».
- Система — снимок системы, память (SMBIOS), загрузка (BCD / GPT / WinRE).
- Диски — диски, SMART, ошибки файловой системы.
- Целостность — проверка без изменений; «ИСПРАВИТЬ целостность (DISM + SFC)»; создание точки восстановления. Если на целевом диске Windows 7, программа запускает только SFC: проверки DISM /CheckHealth, /ScanHealth, /RestoreHealth в Windows 7 не работают (ошибка 87 — это не повреждение).
- Драйверы и BSOD — устройства с ошибками (с расшифровкой кода проблемы), события синих экранов, разбор дампов памяти, справочник кодов BSOD. Для полного разбора (!analyze -v) положите cdb.exe в папку Tools рядом с программой.
- События — ошибки журналов System и Application за выбранный период. В офлайн-режиме читаются файлы *.evtx.
- Сеть — проверка сети до указанного хоста и порта.
- Инструменты ремонта — окна для ремонта выбранной Windows (разделы ниже).

## Мастер «Что случилось?» {#triage}
Выберите симптом: не загружается, синий экран, диск не виден, подозрение на вирус, нет сети, тормозит или перезагружается, не ставятся обновления. Программа проверяет систему только на чтение и показывает находки по степени важности с рекомендуемым действием. Итог сохраняется в triage.txt и triage.json.

## Каталог команд {#catalog}
Обзор → «Каталог команд»: готовые команды Windows с полями параметров и фильтром по категориям — диагностика, DISM/SFC, загрузка/BCD, диски, сеть, восстановление, WinPE.

Цвет полосы слева и метка справа показывают, что делает команда:
- синий — только чтение;
- бирюзовый — открывает окно Windows;
- оранжевый — меняет систему;
- красный — опасно (нужна копия);
- серый — только инструкция, ничего не запускается.
 Каждый запуск подтверждается; bcdboot, bootrec /fixmbr, /fixboot, /rebuildbcd и chkdsk /f /r — дважды. Для офлайн-системы DISM и SFC сами переходят на /Image: и /offwindir. Опасные процедуры (Driver Verifier, удаление обновлений, переустановка) даны только как инструкция — программа их не запускает.

# Инструменты ремонта {#repair}
Все окна работают с выбранной целевой Windows, а не с самой WinPE.

## Реестр офлайн-Windows {#registry}
Просмотр и правка реестра нескольких систем сразу: SYSTEM, SOFTWARE, SAM, SECURITY, DEFAULT, COMPONENTS, NTUSER и UsrClass всех профилей. Поиск, избранное, экспорт .reg. Перед загрузкой куст копируется, каждое изменение подтверждается и сохраняется в резервную копию.

## BCD / Загрузка {#bcd}
Находит хранилища BCD на всех разделах (в том числе на скрытых и ESP), показывает и правит записи, делает резервную копию и восстанавливает из неё, запускает bcdboot. Режимы загрузки: безопасный режим, журнал загрузки, VGA, отладка, без проверки подписи драйверов. Перезагрузка, в том числе сразу в WinRE.

## Автозагрузка и службы {#autoruns}
Run и RunOnce, папки автозагрузки, Winlogon, IFEO, AppInit_DLLs, BootExecute, службы, драйверы, задания планировщика. Отметки «файл не найден» и «подозрительно», быстрый фильтр, отключение с возвратом, удаление, правка команды, режим чистой загрузки с откатом, экспорт в CSV.

## Установленные приложения {#apps}
Список программ выбранной системы. Цвет строки: красный — антивирус или защита (частая причина незагрузки), зелёный — обычная программа, бирюзовый — драйвер или утилита оборудования, синий — Microsoft, оранжевый — папка программы не найдена, серый — обновления и системные компоненты. Принудительное удаление программы, которая мешает Windows загрузиться (например, антивируса): автозапуск отключается, папка уходит в карантин, запись удаления стирается с резервной копией .reg.

## Офлайн-проводник {#explorer}
Файлы выбранной Windows: копирование, карантин, удаление, смена владельца и прав, поиск.

## Мастер исправлений после заражений {#fixes}
Winlogon Shell/Userinit, IFEO, AppInit, политики, прокси, hosts, важные службы, ассоциации файлов, SafeBoot. Сброс Windows Update, сети и WMI, отмена отложенных операций, замена кустов реестра из RegBack.

## BitLocker и драйверы хранилища {#bitlocker}
Разблокировка тома ключом восстановления, паролем или файлом .bek (ключи не пишутся в журнал), состояние, приостановка и возобновление. Если диск не виден: подсказки по Intel VMD/RST, загрузка драйвера (drvload) в WinPE/WinRE, добавление драйвера в офлайн-Windows (DISM /Add-Driver).

## WinRE {#winre}
Вход в среду восстановления при следующей загрузке, восстановление записи WinRE в BCD, «WinRE + WinRepair» — копия winre.wim, в которой первой запускается WinRepair. Она добавляется отдельным пунктом в меню загрузки, флешка не нужна. Там же — штатное меню WinRE и проверка сертификатов Secure Boot 2023.

## Восстановление системы {#rstrui}
rstrui (в том числе для офлайн-Windows из WinPE) и состояние точек восстановления.

## Снятие пароля и разблокировка учётных записей {#password}
Пункт «Снятие пароля и разблокировка учётных записей…» на вкладке «Обзор». Для офлайн-Windows (из WinPE/WinRE): показывает локальные учётные записи из SAM (имя, RID, тип, состояние, есть ли пароль, признак учётной записи Microsoft).
Действия: снять пароль (вход с пустым паролем), снять пароль и включить вход (одной кнопкой для забытого пароля), включить отключённую запись, разблокировать.
Безопасность: перед изменением куст SAM копируется автоматически (откат — «Отменить изменения сеанса»); новый пароль не задаётся и в журнал не пишется. Учётные записи Microsoft офлайн не сбрасываются. После снятия пароля зашифрованные EFS-файлы и сохранённые пароли этой записи станут недоступны.

## Разделы диска (diskpart) {#partition}
Пункт «Разделы диска…» на вкладке «Обзор». Обёртка над diskpart для работы из WinPE/WinRE над физическими дисками. Список дисков и их разделов/томов (номер, смещение, размер, тип, буква, ФС, метка, свободно) и визуальная полоса-шкала; клик по полосе или правый клик по списку — выбор и меню операций.
Операции: создать раздел, удалить, форматировать (NTFS/FAT32/exFAT), назначить/убрать букву, активный раздел (MBR), сжать/разделить, расширить, конвертировать GPT↔MBR.
Все операции необратимы — данные не восстановить. Каждая операция подтверждается; в заголовке диска показаны модель, размер и серийный номер — сверяйте, чтобы не перепутать диск. Инструмент для продвинутых пользователей.

## Цвета в окнах инструментов
Во всех окнах цвет означает одно и то же. Кнопки: синяя — проверка (только чтение), бирюзовая — открывает другой инструмент, оранжевая — меняет систему, красная — опасное действие (например, перезагрузка сейчас), зелёная — защита или отмена, серая — служебная. Строки списков: в «Мастере исправлений» и «Сценариях» — по риску (зелёный — безопасно, оранжевый — меняет, красный — опасно), в «Что случилось?» — по важности (красный — проблема, оранжевый — внимание, зелёный — в порядке).

# Справочник кодов BSOD {#bsod}
Кнопка «Справочник кодов BSOD…» на вкладке «Драйверы и BSOD». Для каждого типового кода синего экрана: что он значит, первый шаг проверки и что важно знать.

- Поиск — по коду (7B, 0x7B, 0x0000007B) или по названию (например, IRQL).
- «Только частые коды» — коды, которые встречаются чаще всего.
- Цвет строки — группа причин: синий — драйвер или программа, оранжевый — память, бирюзовый — диск или загрузка, зелёный — целостность Windows или реестр, красный — оборудование.
- Кнопки «BSOD: события и дампы» и «Разбор дампов» сразу запускают проверки.

Код BSOD — это категория, а не диагноз. Причину показывает дамп (модуль в стеке), журнал событий и проверки дисков, памяти и драйверов. По одному коду нельзя назначать замену железа или переустановку Windows.

Дампы лежат в %SystemRoot%\Minidump (малые) и %SystemRoot%\MEMORY.DMP (полный, если включён).

# Полная диагностика и HTML-отчёт {#report}
«Полная диагностика + HTML-отчёт» на вкладке «Обзор» проверяет систему по 9 разделам и сохраняет отчёт report.html.

- В начале — оценка здоровья и что её снизило.
- Каждый раздел начинается с пояснения: что проверялось.
- Строки на красном фоне — проблемы, на зелёном — проверка пройдена.
- У кодов устройств (например, 22, 28, 43), событий журнала (например, Kernel-Power 41, disk 7), синих экранов и кодов DISM/SFC написано, что они значат и что делать.
- Одинаковые события сгруппированы: сколько раз, когда последний раз и пример сообщения.

# Загрузочная флешка WinPE {#winpe}
Кнопка «Создать загрузочную флешку WinPE с WinRepair…» (вкладка «Обзор» и окно WinRE) собирает флешку, с которой WinRepair запускается сам. Флешка грузится и в UEFI (Secure Boot выключать не нужно), и в BIOS (Legacy).

1. Куда записать — корень флешки, лучше FAT32. Подсказка под полем сразу показывает, что выбрано: флешка (FAT32/NTFS, MBR/GPT), папка или диск с Windows.
2. База образа — одно из трёх:
- установочный образ Windows (ISO, boot.wim, папка или установочная флешка) — ADK не нужен;
- ADK WinPE — чистый минимальный образ; winpe.wim можно указать вручную;
- winre.wim этой системы — со встроенным «Восстановлением системы» (rstrui).
3. Установочный образ — файл .iso или boot.wim либо папка/диск с файлами Windows.

## Образ ISO
После выбора файла .iso программа сразу подключает его и ждёт, пока Windows присвоит ему букву диска (до 30 секунд). Пока идёт подключение, кнопка «Собрать флешку» недоступна. Затем буква подключённого образа появляется в нижней рамке «Папка или диск». После записи флешки образ отключается сам. Если вы закрыли окно, не собирая флешку, образ тоже отключается.

Если подключить не получилось, подключите образ вручную (правый клик по файлу → «Подключить») и выберите его букву в нижней рамке.

## Что делает программа при сборке
- Извлекает WinPE из образа и перепаковывает его в обычное сжатие (так правятся и «авторские» сборки).
- Исправляет путь системы и оболочку в реестре образа, проверяет загрузчики winload.exe и winload.efi.
- Добавляет WinRepair (со встроенной справкой), сценарии, языки и автозапуск.
- Загрузочные файлы берёт из того же установочного образа, иначе из ADK или из этой Windows.
- Для BIOS делает раздел флешки активным и записывает загрузочный код (только на флешку, не на диск с Windows).
- В конце проверяет флешку и отключает образ ISO.

Ход записи boot.wim виден в строке состояния внизу окна. «Отмена» прерывает запись и удаляет недописанный файл. Рабочая копия образа после сборки удаляется, остаются только журналы.

## Флешка уже с WinPE
Кнопка «Флешка уже с WinPE? Сделать загрузочной для BIOS…» нужна, если WinPE скопирован на флешку вручную. Она только делает раздел активным и записывает загрузочный код. Файлы на флешке не удаляются.

## Как загрузиться
Вставьте флешку, при включении откройте Boot Menu (обычно F12, F11, Esc или F9) и выберите флешку: пункт UEFI, а на старых компьютерах — USB-HDD (BIOS/Legacy). WinRepair откроется сам.

Собранный образ — только для личного использования: лицензия Microsoft не разрешает его распространять.

# Сценарии ремонта {#playbooks}
Сценарий — текстовый файл *.wrp с пошаговой процедурой ремонта или с новым симптомом для мастера «Что случилось?». Перекомпилировать программу не нужно.

- Сценарии читаются из папки Playbooks рядом с программой и из Data\Playbooks. Сценарий с тем же id во второй папке заменяет поставляемый.
- Шаги: сообщение, вопрос, подтверждение, команда, исправление, модуль диагностики, проверка. Каждый шаг, который меняет систему, подтверждается отдельно.
- После правки файла нажмите «Перезагрузить список». Ошибки в файлах показываются как «ОШИБКИ РАЗБОРА».

# Командная строка {#cmd}
Кнопка «Командная строка (администратор)…» на вкладке «Обзор» открывает консоль cmd с правами администратора. В WinPE и WinRE права уже полные. В обычной Windows без прав администратора Windows спросит разрешение.

Консоль открывается в корне выбранной целевой Windows. Буквы дисков в WinPE часто не такие, как в обычной Windows: проверьте их командой diskpart → list volume.

Полезные команды:
- dir D:\ — содержимое диска;
- diskpart → list disk, list volume — диски и разделы;
- bcdedit /enum all — записи загрузки;
- dism /Image:D:\ /Cleanup-Image /RestoreHealth — восстановление офлайн-Windows;
- sfc /scannow /offbootdir=D:\ /offwindir=D:\Windows — проверка файлов офлайн-Windows;
- chkdsk D: /f — исправление ошибок диска;
- notepad — Блокнот, через «Файл → Открыть» удобно просматривать диски;
- любая_команда /? — справка по команде.

Команды из консоли не попадают в журнал программы и не отменяются кнопкой «Отменить изменения сеанса».

# Журналы, резервные копии и откат {#data}
Всё, что делает программа, пишется в папку Data рядом с программой. Если эта папка только для чтения, используется %TEMP%\WinRepair.

- Data\Logs\WinRepair_<дата>.log — полный журнал работы, с выводом всех команд;
- Data\Logs\commands_<дата>.log — журнал команд каталога;
- Data\Logs\undo_journal.tsv — список изменений для отката;
- Data\Reports\<время>_<модуль> — отчёты (HTML, triage, вывод команд);
- Data\Backups — резервные копии кустов реестра, BCD, .reg;
- <диск>:\WinRepair_Removed\<время> — карантин файлов на том же диске.

Кнопки на вкладке «Инструменты ремонта»:
- «Отменить изменения сеанса…» — показывает изменения (реестр, файлы, BCD, карантин) и откатывает их в безопасном порядке. После перезапуска предлагает откатить и прошлый сеанс. Перед откатом закройте окна инструментов.
- «Резервные копии: просмотр и очистка…» — сколько копий и сколько места они занимают. После удаления копий откат невозможен.
- «Сохранить журналы и отчёты на диск…» — копирует журналы и отчёты на флешку или другой диск. Это важно, если программа запущена из образа WinPE (с диска X:): после перезагрузки диск X: очищается.

# Командная строка запуска {#switches}
- WinRepair.exe /full — полная диагностика без окна и HTML-отчёт в Data\Reports\<время>_full. Код выхода 0 — отчёт создан, 1 — нет.
- WinRepair.exe /full /out:E:\Reports\PC-01 — то же, отчёт в указанную папку.
- WinRepair.exe /lang:en или /lang:ru — язык интерфейса.

# Язык, справка и файлы рядом с программой {#files}
- WinRepair.ini — язык интерфейса (если папка только для чтения — Data\settings.ini).
- Lang\<код>.txt — дополнительные языки; английский уже встроен в программу.
- Playbooks — сценарии ремонта.
- Tools\cdb.exe — необязательно, полный разбор дампов памяти.
- Data — журналы, отчёты, резервные копии; создаётся сама.

При сборке флешки WinPE папки Playbooks и Lang копируются в образ автоматически.

Справка встроена в программу (Tynychsoft) и не заменяется файлами рядом с ней — в официальной сборке её текст изменить нельзя. Официальная программа — только со страницы Releases на GitHub, файл можно сверить по SHA-256 из релиза.

# Безопасность {#safety}
- Перед каждым изменением — подтверждение и резервная копия.
- Вместо удаления — карантин.
- Все действия записываются в журнал.
- Программа никуда не отправляет данные. Ключи и пароли BitLocker в журнал не попадают.
