# Политика подписи кода (Code signing policy)

Этот файл готовит проект к бесплатной подписи через SignPath Foundation (открытый код). Подпись пока **не подключена**: заявка подаётся, когда у проекта появится история релизов и пользователи.

## Что подписывается
Только `WinRepair_x64.exe` / `WinRepair_x86.exe`, собранные из этого репозитория автоматически в GitHub Actions (`.github/workflows/release.yml`) из исходного кода по тегу версии.

## Роли
- Автор, рецензент и подтверждающий выпуск: владелец репозитория (<ник на GitHub>); двухфакторная защита включена.
- Каждый релиз подтверждается вручную.

## Что делает программа (для заявки)
Диагностика и ремонт офлайн-Windows по явной команде пользователя: просмотр и правка реестра, BCD, автозагрузки, удаление программ, файловые операции. Каждая правка требует подтверждения, делает резервную копию и пишется в журнал. Программа не собирает и не отправляет данные (см. `PRIVACY.md`), не обходит защиту системы, не содержит средств взлома. Права администратора запрашиваются манифестом, так как без них ремонт невозможен.

## Конфиденциальность
См. `PRIVACY.md`. Передачи данных на внешние серверы нет.

## Перед подачей заявки
- [ ] репозиторий публичный, лицензия MIT (есть)
- [ ] несколько релизов с историей скачиваний
- [ ] метаданные exe (название, версия, автор) заполнены (`res/version.h`)
- [ ] описание проекта и ссылка на скачивание на странице репозитория
- [ ] в заявке прямо указано, что инструмент правит реестр и файлы чужой системы по команде пользователя
