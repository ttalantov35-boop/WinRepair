# Инструкция: загрузочная флешка WinPE с WinRepair

## 1. Что понадобится

- Флешка от 2 ГБ, лучше 8 ГБ и больше.
- `WinRepair_x64.exe`, запущенный **от имени администратора**.
- **Основа «Установочный образ Windows» (ADK не нужен, проще всего).** Достаточно ISO-образа Windows 10/11 (с сайта Microsoft «Скачать Windows») или установочной флешки Windows. Программа сама берёт из него чистый WinPE; WinRepair стартует первым, `rstrui` работает. Образ лучше той же версии и разрядности, что ваша Windows.
- **Основа ADK WinPE.** Нужны установленные *Windows ADK* и *Windows PE add-on*. Результат тот же; удобно, если ADK уже стоит.
- Запасная основа: `winre.wim` вашей системы. ADK ставить не нужно, но WinRepair придётся запускать вручную: язык → «Дополнительно» → «Командная строка» → `winrepair`.

## 2. Какая файловая система нужна

| Файловая система | Загрузка на UEFI (Secure Boot включён) | Совет |
|---|---|---|
| **FAT32** | Да | **Используйте её.** Загрузчик Microsoft читает только FAT32. |
| NTFS | Нет | Не подходит |
| exFAT | Нет | Не подходит |

Ограничения FAT32:
- Файл не больше 4 ГБ (образ WinPE меньше, это не мешает).
- Встроенное форматирование Windows принимает только до 32 ГБ. Для флешки побольше используйте `diskpart` (ниже) или сторонние форматировщики.
- Название тома любое, например `WINPE`.

## 3. Флешка без данных

1. Вставьте флешку и запомните её букву (например, `E:`). **Проверьте букву внимательно**, форматирование стирает всё.
2. Проводник → правый клик по флешке → **Форматировать** → **FAT32** → **Начать**.
3. Для флешки больше 32 ГБ откройте командную строку от администратора:
   ```
   diskpart
   list disk
   select disk N        (номер флешки, не диска с Windows!)
   clean
   create partition primary
   format fs=fat32 quick label=WINPE
   active
   assign
   exit
   ```
   Команда `clean` стирает флешку целиком: номер диска проверяйте по размеру.

## 4. Флешка с данными, которые нельзя стереть

Записать образ без форматирования можно, **только если флешка уже в FAT32** и на ней есть около 1 ГБ свободного места. Файлы WinPE ложатся в корень рядом с вашими данными, ничего не удаляется. Но если в корне уже есть папки `EFI`, `boot`, `sources` или файл `bootmgr`, их содержимое смешается с образом.

- **NTFS или exFAT:** перевести в FAT32 без потери данных нельзя (`convert` работает только в обратную сторону). Скопируйте данные на компьютер, отформатируйте флешку в FAT32, верните данные.
- **Лучший вариант:** отдельная маленькая флешка только под WinPE.

## 5. Создание флешки в программе

1. WinRepair → вкладка **Обзор** (кнопка выделена оранжевым) или «Инструменты ремонта» → **«Создать загрузочную флешку WinPE с WinRepair…»**.
2. В окне выберите:
   - **Куда:** корень флешки (например, `E:\`). Можно указать и папку (по умолчанию `D:\WinPE_WR`), а потом скопировать её содержимое на флешку вручную.
   - **Основа:** **«Установочный образ Windows»** (ADK не нужен), **«ADK WinPE»** или `winre.wim` этой системы.
   - **Установочный образ Windows:** файл `.iso`, буква диска с подключённым образом/установочной флешкой или папка с `sources\boot.wim`. Нужен только для первой основы.
3. Подтвердите. Сборка идёт несколько минут. В конце журнала должна быть строка **«Автозапуск: winpeshl.ini → wpeinit → WinRepair»**. Если вместо неё предупреждение о защите от перезаписи (0x780), вы выбрали `winre.wim`: пересоберите на основе установочного образа или ADK.
4. Дождитесь завершения и извлекайте флешку через **Безопасное извлечение**.

## 6. Загрузка с флешки

1. Вставьте флешку в нужный компьютер и включите его.
2. Сразу нажмите клавишу выбора загрузки: чаще **F12**, **F11**, **Esc** или **F8** (зависит от производителя).
3. Выберите **UEFI: название флешки**. **Secure Boot можно оставить включённым.**
4. Загрузится WinPE, и сразу откроется WinRepair.
5. В списке **«Целевая ОС»** выберите Windows, которую нужно чинить.

## 7. Частые вопросы

- **Старый ПК без UEFI (Legacy/BIOS).** Дополнительно сделайте флешку загрузочной: `bootsect /nt60 E: /force /mbr` (из папки ADK). Программа предупреждает об этом в журнале. На современных ПК не нужно.
- **Флешки нет в меню загрузки.** Проверьте FAT32 и включённую загрузку с USB; на некоторых ПК временно выключите **Fast Boot**.
- **Можно ли раздать готовую флешку?** Нет: лицензия Microsoft запрещает распространять образ. Каждый собирает свою одной кнопкой.
- **WinRepair не нашёл Windows.** Проверьте, виден ли диск (может понадобиться драйвер хранилища, например Intel VMD/RST). Раздел «BitLocker и драйверы хранилища»; если диск зашифрован BitLocker, сначала разблокируйте его.
