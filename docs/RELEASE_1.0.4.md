## 1. Снятие пароля и разблокировка учётных записей 🔑

Окно для **офлайн-Windows** (из WinPE/WinRE). Показывает локальные учётные
записи из куста **SAM** выбранной системы: имя, RID, тип (пользователь /
встроенный администратор / гость), состояние (включена / отключена /
заблокирована), есть ли пароль, признак учётной записи **Microsoft**.

Действия над выбранной записью:
- **Снять пароль** — вход с пустым паролем.
- **Снять пароль и включить вход** — одной кнопкой (для забытого пароля).
- **Включить** отключённую запись (например встроенного Администратора).
- **Разблокировать** заблокированную запись.

Как сделано: снятие пароля = обнуление длины NT/LM-хеша в значении `V`
(работает Win7–Win11, в т. ч. формат AES в Win10/11); состояние — биты ACB в
значении `F`. Листинг и правка — через офлайн-движок реестра (`offreg`).

Безопасность: перед изменением куст SAM **копируется автоматически** (откат —
«Отменить изменения сеанса»); каждое действие пишется в журнал; **новый пароль
не задаётся и в журнал не попадает**. Учётные записи Microsoft офлайн не
сбрасываются (помечаются серым, с пояснением). Предупреждение о потере
EFS-файлов и сохранённых паролей.

Файлы: `src/ui_password.cpp`, `src/modules/sampwd.*`.

## 2. Менеджер разделов диска (diskpart) 💽

Окно «Разделы диска» — обёртка над **diskpart** для работы из WinPE/WinRE над
физическими дисками. Листинг — через **Windows API** (надёжно, не зависит от
языка diskpart).

Показывает:
- список дисков (модель, размер, GPT/MBR, шина, серийный номер);
- разделы и тома: №, смещение, размер, тип (EFI/MSR/восстановление/основной),
  буква, ФС, метка, свободно; показываются и **свободные области**;
- **визуальную полосу-шкалу** разделов (цветные сегменты пропорционально
  размеру; клик по полосе выбирает раздел).

Операции (всё скриптами diskpart):
- создать раздел, удалить, форматировать (NTFS/FAT32/exFAT);
- назначить / убрать букву; активный раздел (MBR);
- **сжать / разделить**, расширить;
- конвертировать GPT ↔ MBR.

Наглядность: крупные шрифты, цвета строк, крупный цветной заголовок диска,
**правый клик = меню операций**, автообновление списка и строка статуса
(«Выполняется…» → «Готово…»). Размеры везде в ГБ/МБ (в диалогах — пояснение
«1 ГБ = 1024 МБ»).

Безопасность: **все операции необратимы** — крупное красное предупреждение и
понятное подтверждение каждой операции; в заголовке показаны модель/размер/
серийный номер, чтобы не перепутать диск. Для продвинутых пользователей.
Действия пишутся в журнал.

Файлы: `src/ui_partition.cpp`, `src/modules/partition.*`.

## 3. Двуязычный интерфейс (RU/EN) 🌐

Расшифровки кодов переведены на английский и выбираются по языку интерфейса:
коды проблем устройств (`devprob.h`), события журналов и коды DISM/SFC
(`event_explain.h`), справочник BSOD (`bsod_catalog.h`). Двуязычны HTML-отчёт,
окно «Справочник кодов BSOD», журнал, мастер «Что случилось?», окна снятия
пароля и разделов, а также **единицы размера** (КБ/МБ/ГБ ↔ KB/MB/GB).

## Для сайта: полный список возможностей WinRepair

Один `WinRepair.exe`, без установки; не нужны .NET, PowerShell, VC++ Redist.
Работает с несколькими установленными системами сразу (C:, D:…). Запуск из
обычной Windows, из WinPE или WinRE.

**Диагностика и отчёты**
- Полная диагностика → подробный **HTML-отчёт** (содержание, пояснения,
  проблемы на красном фоне, нормы — на зелёном).
- Мастер **«Что случилось?»** — по симптому (не грузится, синий экран, диск не
  виден, заражение, нет сети, тормоза/перезагрузки, не ставятся обновления).
- Диски и SMART, события журналов, разбор дампов, **справочник кодов BSOD**.

**Ремонт**
- **Офлайн-редактор реестра** (как regedit) для нескольких систем сразу.
- **BCD и загрузка**: хранилища на всех томах, правка, бэкап/восстановление,
  `bcdboot`, режимы загрузки (безопасный режим и др.).
- **Автозагрузка и службы** (как Autoruns + msconfig), чистая загрузка.
- **Мастер лечения заражения** (Winlogon/IFEO/AppInit/политики/прокси/hosts/
  службы/ассоциации/SafeBoot/Update/сеть/WMI/отложенные операции/RegBack).
- **Установленные приложения** офлайн-системы (удаление мешающих запуску).
- **Офлайн-проводник** (копирование, карантин, права, поиск).
- 🔑 **Снятие пароля и разблокировка учётных записей** (см. выше).
- 💽 **Менеджер разделов диска (diskpart)** (см. выше).
- **BitLocker и драйверы хранилища** (разблокировка, drvload, DISM /Add-Driver).
- **Восстановление системы** (`rstrui`, точки восстановления).

**WinRE и WinPE**
- **WinRE**: вход в среду восстановления, починка записи WinRE, **WinRE +
  WinRepair** (образ, который запускает WinRepair первым; учитывает UEFI/BIOS и
  BitLocker), проверка сертификатов Secure Boot 2023.
- **Своя загрузочная флешка WinPE с WinRepair** — одной кнопкой: собственная
  WinPE, где WinRepair стартует сам; основа ADK WinPE или `winre.wim`; загрузка
  с FAT32-флешки при включённом Secure Boot. Поддержка Windows on ARM (ARM64).

**Каталог команд (84 команды)**
- Фильтр по категориям, поля параметров, точная командная строка; каждое
  выполнение — с подтверждением, опасные — дважды; вывод в журнал и отчёты.
  Многие команды нативные (без PowerShell); DISM/SFC для офлайн-цели сами
  переключаются на `/Image` и `/offwindir`.

**Сценарии (playbooks)**
- Файлы `*.wrp` добавляют процедуры ремонта и симптомы **без пересборки**.

**Безопасность**
- Подтверждение перед каждым изменением; **резервная копия перед каждым
  изменением** (кусты, BCD, `.reg` ветки); карантин вместо удаления; полный
  журнал изменений; **откат всех изменений сеанса в один клик**. Программа
  ничего никуда не отправляет.
