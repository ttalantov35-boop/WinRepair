# Локализация (RU / EN и другие языки)

## Как это устроено
Исходные строки в коде — русские. Перевод подставляется **на выходе**: в окнах, диалогах, журнале (окно и файл), HTML-отчёте. Логика программы не затрагивается
(например, состояния «Отключено» сравниваются в оригинале), поэтому добавление языка не может сломать работу.
* Словарь `lang/en.txt` встроен в exe (ресурс RCDATA) — программа остаётся одним файлом.
* Формат: `русский текст ==> English text`. `{}` — подстановочный знак для чисел и имён (`Томов: {}, заблокировано: {} ==> Volumes: {}, locked: {}`).
  Экранирование: `\n`, `\r`, `\t`, `\\`. Строки с `#` — комментарии. Подставляемые значения, содержащие русский текст, переводятся рекурсивно.
* Фразы без перевода остаются на русском (безопасная деградация).

## Выбор языка
Приоритет: параметр `/lang:en|ru` → файл `WinRepair.ini` рядом с exe (`lang=en`) → `Data\settings.ini` → язык системы (русская → RU, иначе EN).
Кнопка «English» / «Русский» вверху справа сохраняет выбор и перезапускает программу.

## Свой язык или правка перевода (без пересборки)
1. Скопируйте `lang\en.txt` в `Lang\de.txt` рядом с exe (в пакете папка `Lang\` уже есть) и переведите правую часть строк.
2. Запустите `WinRepair.exe /lang:de` (или впишите `lang=de` в `WinRepair.ini`). Сначала загружается встроенный английский, затем `Lang\en.txt`, затем `Lang\de.txt` —
   непереведённые фразы будут английскими, а не русскими.

## Для разработчика: добавление строк
1. Пишите новые русские строки в коде как обычно (`fmt`, конкатенация, `L"…"` в окнах).
2. `python3 tools/i18n_extract.py --missing` — список строк без перевода; `--numbered > lang/keys.txt` — пронумерованный список для переводчика.
3. Переводы кладите в `lang/tr/NNN.txt` строками `N|English` (`<sp>` — пробел в начале/конце) и соберите словарь: `python3 tools/i18n_merge.py`.
4. `python3 tools/i18n_check.py` — совпадение числа `{}`, дубликаты, слишком короткие шаблоны. Тесты: `./run_tests.sh`.
Строки с `+` между литералом и значением (`"Ошибка: " + текст`) извлекаются как шаблоны `Ошибка: {}` — переводите их как есть.

## Что не переводится
Фильтры диалогов «Открыть/Сохранить файл», заголовки CSV/JSON-файлов отчётов (машинные форматы) и тексты внутри `.wrp`-сценариев пользователя,
для которых нет записи в словаре. Состав словаря: 1431 из 1438 найденных строк (остальные — служебные: названия языков и маски файлов).
