# Анализ аналогов и концепция WinRepair («швейцарский нож» для ремонта Windows»)


## 4. Что реализовано в этой версии для WinRE
* Вход в WinRE **при следующей загрузке** и **с немедленной перезагрузкой**: онлайн — `reagentc /boottore`; из WinPE — одноразовая загрузка (`bcdedit /bootsequence`)
  в запись WinRE целевой ОС (ReAgent.xml → BCD). Если записи нет, но `Winre.wim` найден (в т.ч. на скрытом разделе) — запись создаётся автоматически.
* **Windows RE + WinRepair**: копия вашего `winre.wim` + WinRepair.exe, `winpeshl.ini` запускает WinRepair первым, после выхода открывается штатное меню WinRE.
  Оригинальный WinRE и его запись BCD не меняются; создаётся отдельный пункт BCD; удаление — одной кнопкой.
* Определение, что программа запущена внутри WinRE (баннер `[WinRE]`), выход в штатное меню, перезагрузка при закрытии.
* Сохранение журналов/отчётов на диск (ОЗУ-диск WinPE/WinRE очищается при перезагрузке).
* Проверка Secure Boot: есть ли в KEK/db сертификаты 2023 (срок старых — июнь и 19 октября 2026).
