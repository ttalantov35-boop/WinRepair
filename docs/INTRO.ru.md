# WinRepair Toolkit
### Windows не загружается? Один файл — и вы снова у руля.

*Tynychsoft представляет*

---

## Знакомая беда

Чёрный экран. Синий экран. Бесконечная перезагрузка. Антивирус, который сам же и «убил» запуск системы. Рабочий компьютер, на котором завтра сдача проекта.

Обычно в такие минуты начинается квест: найти вторую машину, скачать чужую сборку WinPE неизвестного происхождения, перебрать десять утилит, каждая из которых умеет «чуть-чуть». А время идёт.

**WinRepair Toolkit — это ответ на всё это одним файлом.** Без установки. Без .NET. Без PowerShell. Просто `WinRepair.exe`.

## Что внутри

**🔧 Мастерская для больной системы.** Офлайн-реестр уровня regedit. Редактор BCD и режимов загрузки. Автозагрузка и службы в духе Autoruns. Офлайн-проводник. Принудительное удаление программы, из-за которой Windows не стартует. Всё это — для *другой* Windows, которая лежит на диске и не может включиться.

**🔑 Забыли пароль Windows?** Снятие или разблокировка пароля локальной учётной записи офлайн — прямо в кусте SAM выбранной Windows, вход в систему без переустановки. (Пароль от аккаунта Microsoft так сбросить нельзя.) Перед изменением SAM сохраняется автоматически.

**💽 Разделы диска.** Встроенный менеджер разделов: создание, удаление, форматирование, сжатие, разделение, расширение и назначение буквы — с наглядной шкалой, в том числе офлайн в WinRE/WinPE. Для продвинутых — операции с разделами необратимы, поэтому каждая выполняется с подтверждением.

**⌨️ Командная строка администратора.** Встроенная консоль с правами администратора: `diskpart`, `sfc`, `dism` и другие команды прямо из программы.

**🧭 Мастер «Что случилось?».** Не знаете, с чего начать? Выберите симптом — и программа сама проверит BitLocker, диск, разделы, загрузчик, кусты реестра, обновления, дампы, службы и сеть, а затем покажет находки по степени важности и предложит действие. Ничего не делается без вашего «да».

**💾 Своя загрузочная флешка WinPE.** Одна кнопка — и у вас флешка, которая загружается *сама по себе* и первой открывает WinRepair. Никаких чужих сборок. Даже «Восстановление системы» (`rstrui`) работает прямо оттуда: можно откатить Windows к точке восстановления, не загружая её. Работает при включённом Secure Boot.

**↩️ Откат в один клик.** Программа ведёт журнал всего, что изменила: куски реестра, файлы, BCD, карантин. Передумали — одна кнопка возвращает всё в безопасном порядке. Даже после перезапуска.

**📱 И на ARM тоже.** Нативная сборка для Windows on ARM: Snapdragon-ноутбуки больше не остаются без инструмента.

**🛡️ Безопасность как привычка.** Подтверждение перед каждым действием, резервная копия перед каждым изменением, карантин вместо удаления, полный журнал. И ни байта в интернет — программа ничего никуда не отправляет.

## Как это выглядит на практике

1. Скачали `WinRepair_x64.exe`.
2. Нажали «Создать загрузочную флешку WinPE с WinRepair…» — получили свой аварийный носитель.
3. Загрузились с неё на «мёртвом» компьютере — WinRepair открылся сам.
4. «Что случилось?» → симптом → находки → исправление. Или точка восстановления через `rstrui`.
5. Что-то пошло не так? «Откатить изменения сессии».

Пять шагов вместо вечера поисков.
