# Участие в проекте
1. Форк → ветка `feature/<название>` → Pull Request.
2. Перед PR запустите `./run_tests.sh` (Linux/WSL/MSYS2): тесты ядра, сценариев и словаря.
3. Строки интерфейса пишутся по-русски в коде; английский перевод — в `lang/extra.txt` (формат `по-русски ==> English`), затем `python3 tools/i18n_merge.py`. См. `docs/LOCALIZATION.md`.
4. Новые способы ремонта удобнее всего оформлять как сценарии `Playbooks/*.wrp` (`docs/PLAYBOOKS.md`) — перекомпиляция не нужна.
5. Правьте версию только в `res/version.h` и записывайте изменения в `CHANGELOG.md`.
6. Любая правка чужой системы должна: спрашивать подтверждение, делать резервную копию, писать в журнал.
Об уязвимостях сообщайте по `SECURITY.md`, не через публичные issues.
