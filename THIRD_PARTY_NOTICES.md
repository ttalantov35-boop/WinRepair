# Сторонние компоненты
Код программы написан с нуля на C++17 с использованием Win32 API и статической CRT Microsoft (лицензия на распространяемые компоненты Visual Studio / Microsoft C++ Runtime).
SHA-256 реализован самостоятельно по FIPS 180-4. Сторонние библиотеки в exe не включены.
Программа вызывает штатные утилиты Windows (bcdedit, DISM, reagentc, manage-bde, sfc и др.), которые не поставляются с пакетом и принадлежат Microsoft.
Данные кодов BSOD (`bsod-codes.json`) — предоставлены автором проекта; проверьте права на их распространение перед публикацией.
